# Documentação do Trabalho de POO

## Para entregar / compartilhar com o grupo

A pasta **`word/`** tem tudo em `.docx`, pronto para compartilhar:

| Arquivo | Para que serve |
|---|---|
| `1 - Diagrama de Classes.docx` | **Atividade 1** do enunciado. Traz o diagrama de classes e o de camadas. |
| `2 - Guia de Defesa Oral.docx` | Perguntas prováveis do professor com a resposta pronta e o arquivo/linha que prova cada uma. |
| `3 - Roteiro de Apresentacao.docx` | Setup antes de apresentar e a sequência exata da demonstração. |
| `4 - Banco de Dados.docx` | Como o banco foi montado e como reproduzir em outra máquina. |

> Ao abrir no Word, o Sumário se preenche sozinho. No Google Docs ele pode aparecer vazio — use *Inserir > Sumário* se precisar.
